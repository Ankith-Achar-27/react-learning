- Sending data to APIs
- Creating and updating data
- Working with backend resources

### 7. Testing

- Vitest

### 8. Deployment
- Building React applications
- Deploying React applications

### 9. Modern React
- React 19 updates
- Modern React features and patterns

### 10. TypeScript with React

- Exploring AI-assisted React development
